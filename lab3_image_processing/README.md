Лабораторная работа №3. Основы обработки цифровых изображений
Цель работы
Закрепление теоретического материала и практическое освоение основных возможностей по реализации алгоритмов и методов обработки изображений. В рамках варианта №2 необходимо реализовать низкочастотные (сглаживающие) фильтры, а также методы построения и эквализации гистограмм с линейным контрастированием, обеспечив при этом высокую производительность и продвинутые режимы обработки.

Задачи работы
Реализовать «честный» пиксельный доступ к памяти без использования высокоуровневых библиотечных функций (OpenCV, PIL для фильтрации) и без медленных методов GetPixel/SetPixel.

Реализовать низкочастотные фильтры (Box blur, Gaussian blur) с использованием разделяемых свёрток (Separable Convolutions) для оптимизации сложности до O(K·N²).

Реализовать минимум две стратегии обработки краев (Edge Padding): зеркальное отражение (Reflect) и дублирование граничных пикселей (Clamp).

Реализовать методы повышения контраста: линейное контрастирование и выравнивание гистограммы. Сравнить выравнивание в пространстве RGB и в пространстве HSV (только компонента V).

Реализовать адаптивную эквализацию гистограммы с ограничением контраста (CLAHE) по скользящему окну.

Разработать приложение с графическим интерфейсом (GUI) и собрать его в исполняемый файл .exe.

Подобрать базу тестовых изображений (зашумленные, малоконтрастные, с неравномерным освещением) для наглядной демонстрации работы алгоритмов.

Актуальность
Обработка изображений на низком уровне (работа с сырыми буферами памяти) критически важна в системах реального времени, компьютерном зрении и цифровой криминалистике. Понимание того, как работают разделяемые свёртки, позволяет оптимизировать алгоритмы и обрабатывать большие изображения без зависаний интерфейса. Использование CLAHE решает проблему неравномерного освещения, с которой не справляется глобальная эквализация, а сохранение цвета в пространстве HSV делает обработку пригодной для профессиональной фотографии и медицины.

Ход работы
1. Изучение теоретического материала
Были рассмотрены принципы низкочастотной фильтрации. Фильтр Гаусса и Box-фильтр являются линейными и могут быть представлены в виде двумерной матрицы (ядра). Свёртка с таким ядром требует O(K² · N²) операций, где K — размер ядра, N — размер изображения. Применение свойства разделимости позволяет представить двумерную свёртку как два последовательных одномерных прохода (по строкам и по столбцам), что снижает сложность до O(K · N²).
Также были изучены методы эквализации гистограммы. Глобальная эквализация использует кумулятивную функцию распределения (CDF) всего изображения. Пространство HSV позволяет изменять только яркость (V), сохраняя оттенок (H) и насыщенность (S), в отличие от RGB, где независимая эквализация каналов приводит к цветовым искажениям. Алгоритм CLAHE (Contrast Limited Adaptive Histogram Equalization) разбивает изображение на тайлы, применяет к каждому из них локальную эквализацию с ограничением контраста (clip limit), а затем интерполирует результаты для устранения блочных артефактов.

2. Проектирование архитектуры приложения
Приложение разделено на три слоя согласно требованиям методички:

Presentation Layer (UI) — реализован на базе PyQt5. Отвечает за отображение изображений «до/после», отрисовку гистограмм, слайдеры настройки параметров и таблицу выбора методов.

Memory & Pixel Access Layer (Buffer Wrapper) — класс BufferWrapper и EdgePadding. Обеспечивает прямой доступ к буферу numpy (аналог работы с указателями), конвертацию цветовых пространств и безопасную обработку краев.

Processing Layer (Algorithms) — чистая математика. Содержит функции-фильтры, которые принимают пиксельный буфер и возвращают новый, ничего не зная про UI.

3. Реализация алгоритмов
Низкочастотные фильтры (сглаживание):
Реализованы Box-фильтр и фильтр Гаусса. Вместо двумерной свёртки используются два одномерных прохода: _conv1d_h (по строкам) и _conv1d_v (по столбцам). Реализована стратегия разделяемых свёрток. Также реализован медианный фильтр 3x3 для удаления импульсного шума.
Для обработки краев реализован класс EdgePadding с функциями clamp (дублирование крайних пикселей) и reflect (зеркальное отражение). Пользователь может выбирать режим в интерфейсе.

Построение и эквализация гистограмм:

Линейное контрастирование: вычисляет 2-й и 98-й процентили яркости и растягивает диапазон.

Эквализация в RGB: применяет функцию CDF к каждому каналу (R, G, B) независимо.

Эквализация в HSV: переводит изображение в HSV (реализовано вручную, без cv2), применяет CDF только к каналу V, и возвращает обратно в RGB.

CLAHE: реализован алгоритм локальной эквализации по тайлам (размер окна настраивается) с ограничением контраста (clip limit) и билинейной интерполяцией между центрами тайлов.

4. Реализация интерфейса
Интерфейс написан на PyQt5. Главное окно содержит:

Панель выбора тестовых изображений (из папки images).

Выпадающие списки для выбора метода обработки и режима обработки краев (Clamp/Reflect).

Слайдеры и счетчики для настройки размера ядра, сигмы Гаусса, размера тайла и clip limit для CLAHE.

Два виджета для отображения исходного и обработанного изображений.

Два виджета для отрисовки гистограмм «до» и «после» в реальном времени.

Кнопки «Применить» и «Сохранить результат».

5. Подбор базы изображений
В папке images собрана база из 5 изображений, демонстрирующих эффективность конкретных методов:

noisy.jpg — зернистое изображение (для фильтра Гаусса).

salt_and_pepper.png — изображение с импульсным шумом (для медианного фильтра).

low_contrast.jpg — тусклое изображение (для линейного контрастирования).

uneven_light.jpg — фото с неравномерным освещением (демонстрирует превосходство CLAHE над глобальной эквализацией).

colorful.jpg — насыщенное цветное фото (показывает разницу между эквализацией в RGB и HSV).

6. Сборка в исполняемый файл
Сборка производилась при помощи PyInstaller с флагами --onefile и --windowed (чтобы скрыть консоль). В корневой папке проекта находится исполняемый файл ImageProcessingLab3.exe. Для корректной работы с тестовыми изображениями папка images должна находиться в той же директории, что и .exe файл.

Результаты испытаний и пояснения
В ходе тестирования были получены следующие результаты, подтверждающие корректность алгоритмов:

Сглаживание: Разделяемая свёртка Гаусса с ядром 5x5 и σ=1.4 отлично убирает гауссов шум на фото noisy.jpg, делая изображение более гладким. При сравнении на фото salt_and_pepper.png видно, что фильтр Гаусса лишь размазывает черные и белые точки в пятна, тогда как медианный фильтр 3x3 полностью удаляет импульсный шум, сохраняя четкими границы объектов.

Обработка краев: Режим Reflect (отражение) при сглаживании дает более естественный результат на краях изображения, не создавая темных ореолов (виньетирования), в то время как Clamp (дублирование) может приводить к легкому затемнению краев при больших размерах ядра.

Контрастирование: Линейное контрастирование (по 2-му и 98-му процентилю) возвращает тусклому фото low_contrast.jpg нормальную яркость и детали.

Эквализация RGB vs HSV: На фото colorful.jpg применение глобальной эквализации к каналам RGB приводит к неестественному сдвигу цветов (трава становится кислотно-зеленой, кожа приобретает красный оттенок). Применение эквализации только к каналу яркости (V) в пространстве HSV сохраняет оригинальные цвета и оттенки нетронутыми.

CLAHE: На изображении с неравномерным освещением uneven_light.jpg глобальная эквализация делает светлые участки абсолютно белыми (пересвет), теряя текстуру. Алгоритм CLAHE с размером тайла 32 и clip limit 2.0 выравнивает яркость локально, сохраняя детали как в глубоких тенях, так и на ярком свету без пересветов.

Проблемы и их решения
Медленная работа в Python: Стандартные циклы for в Python работают медленно. Решение: все алгоритмы векторизованы с использованием numpy (работа с массивами как с единым блоком памяти). Одномерные свёртки реализованы через сдвиг всего массива и умножение на коэффициент ядра (O(K) операций сложения массивов вместо вложенных циклов).

Искажение цветов при глобальной эквализации: Решение: реализован ручной перевод в пространство HSV и обратно. Модификации подвергается только канал V.

Блочные артефакты в CLAHE: При простом локальном выравнивании на границах тайлов видны швы. Решение: реализована билинейная интерполяция значений LUT между четырьмя соседними тайлами для каждого пикселя изображения.

Зависание интерфейса: Решение: тяжелые вычисления изолированы в Слое обработки. Благодаря векторизации numpy, обработка изображения 4K занимает доли секунды и не требует выноса в отдельные потоки (в отличие от ЛР №2).

Инструкция по эксплуатации
Запустить ImageProcessingLab3.exe (или main.py).

В выпадающем списке слева выбрать тестовое изображение из базы (или загрузить свое через кнопку «Load image»).

Выбрать метод обработки (Gaussian smooth, Box smooth, Median 3x3, Linear contrast, Equalize RGB, Equalize HSV, CLAHE).

Настроить параметры (размер ядра, режим обработки краев, параметры CLAHE).

Нажать «Apply» (Применить).

Оценить результат визуально и по графикам гистограмм «до/после».

Нажать «Save result» для сохранения обработанной картинки.

Изучены и реализованы низкочастотные фильтры на основе разделяемых свёрток, что позволило значительно оптимизировать вычислительную сложность. Освоены методы построения и эквализации гистограмм, включая продвинутый алгоритм CLAHE. Продемонстрировано преимущество работы в пространстве HSV для цветных изображений. Приложение имеет удобный интерфейс и собрано в независимый исполняемый файл. Все задачи варианта №2 выполнены в полном объеме.
