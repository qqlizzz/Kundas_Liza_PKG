Лабораторная работа 1. Цветовые модели: RGB — CMYK — HLS

Приложение для интерактивного преобразования цвета между тремя цветовыми моделями: RGB, CMYK (с алгоритмами цветоделения UCR и GCR) и HLS.

Вариант № 2: RGB — CMYK — HLS.

Автор: Кундас Лиза, группа 12Б.

Возможности
Интерактивное изменение цвета через ползунки, поля ввода и HEX-поле.
Автоматический пересчёт цвета во всех трёх моделях при изменении любой координаты.
Динамическая окраска дорожек ползунков в текущий цвет.

Два алгоритма цветоделения CMYK:
UCR (Under Color Removal) — удаление подложечного цвета.
GCR (Gray Component Replacement) — замена серой компоненты.

Две стратегии обработки выхода за границы RGB:
Clipping — обрезание.
Scaling — пропорциональное масштабирование.

Цветовые модели и формулы
RGB — CMYK
K = 1 - max(R/255, G/255, B/255)
C = (1 - R/255 - K) / (1 - K)
M = (1 - G/255 - K) / (1 - K)
Y = (1 - B/255 - K) / (1 - K)

Обратный перевод:
R = 255 * (1 - C) * (1 - K)
G = 255 * (1 - M) * (1 - K)
B = 255 * (1 - Y) * (1 - K)

Алгоритмы цветоделения
UCR (Under Color Removal) — удаление подложечного цвета. Работает преимущественно в глубоких тенях, где все три компонента CMY высоки. Часть цветных компонентов заменяется чёрным. Это экономит краску и делает тени более глубокими.
GCR (Gray Component Replacement) — замена серой компоненты. Работает во всём диапазоне цветов: если C = M = Y, вся серая составляющая заменяется одной чёрной краской. Это уменьшает расход краски и улучшает стабильность печати.

RGB — HLS
Модель HLS — цилиндрическая: H (Hue) — оттенок в градусах 0–360, L (Lightness) — светлота 0.0–1.0, S (Saturation) — насыщенность 0.0–1.0.

Выход за границы цветового охвата
При переводе цвета между моделями результат может оказаться вне допустимого диапазона. Возможны две стратегии:
Clipping — простое обрезание до границ.
Scaling — пропорциональное сжатие всего диапазона с сохранением соотношений между каналами.
