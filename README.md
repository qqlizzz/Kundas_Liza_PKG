Цель работы
Изучить цветовые модели RGB, CMYK и HLS, освоить математические преобразования между ними, а также разработать приложение, наглядно демонстрирующее эти преобразования в интерактивном режиме.

Задачи работы
Изучить теоретические основы моделей RGB, CMYK и HLS.
Освоить формулы взаимного перевода между ними.
Изучить алгоритмы цветоделения UCR и GCR.
Изучить стратегии обработки выхода за границы охвата — Clipping и Scaling.
Изучить понятие цветового охвата и цветовой график МКО.
Реализовать все преобразования вручную, без сторонних библиотек.
Разработать приложение с архитектурой MVVM.
Реализовать три способа задания цвета: ползунки, поля ввода, палитра.
Обеспечить автоматический пересчёт всех моделей при изменении одной координаты.
Добавить предупреждение о выходе за границы RGB.
Написать автотесты для проверки математики.
Собрать EXE и разместить проект на GitHub.

Актуальность
Понимание цветовых моделей необходимо в веб-дизайне, полиграфии, разработке графических редакторов и обработке изображений. Проблема цветового охвата особенно важна: яркие цвета на экране часто невозможно точно воспроизвести на печати.

Ожидаемые результаты
Работающее приложение с тремя моделями одновременно.
Корректные преобразования, проверенные 12 автотестами.
Переключаемые алгоритмы UCR/GCR и стратегии Clipping/Scaling.
EXE для Windows и исходный код на GitHub.

Вывод
Работа позволяет освоить теоретические основы цвета и получить практические навыки разработки GUI-приложения с корректной архитектурой и тестами.
